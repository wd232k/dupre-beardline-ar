# DUPRE Beardline AR

Camera-based beard shaping guide.

Open the app after GitHub Pages deployment: https://wd232k.github.io/dupre-beardline-ar/

Deploys automatically through `.github/workflows/pages.yml` on pushes to `main`. GitHub Pages must be configured with Source: GitHub Actions.

Camera frames stay in your browser. The guides are approximate and should be checked before shaving.
